# BeeCam hardware documentation

Read README.md before edits. This repository contains the camera hardware design,
not tag-review data, detector training or biological analyses.

- Keep confirmed dimensions distinct from photo inferences and placeholders.
- Use docs/js/data.js as the part/dimension source; regenerate drawings and exports.
- Preserve original reference photos; keep them and private notes out of Git.
- Publish only docs/. Use relative URLs and vendored runtime dependencies.
- Run data checks, privacy audit and browser checks before publication.
- Do not mark this schematic as fabrication-ready or silently resolve unknown dimensions.
